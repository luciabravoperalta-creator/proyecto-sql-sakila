Data Project: Lógica de Consultas SQL

1. Descripción del proyecto

Este proyecto tiene como objetivo aplicar los conocimientos de SQL para consultar y analizar una base de datos de una empresa de alquiler de películas, basada en la base de datos Sakila.

A través de 64 ejercicios prácticos, se trabajan diferentes operaciones de consulta, filtrado, agrupación y combinación de datos, así como la creación de vistas y tablas temporales.

2. Herramientas utilizadas

PostgreSQL: sistema de gestión de bases de datos.

DBeaver: herramienta utilizada para conectarse a la base de datos y ejecutar las consultas SQL.

GitHub: plataforma utilizada para documentar y compartir el proyecto.

3. Desarrollo del proyecto

El proyecto se desarrolla a través de los siguientes pasos:

Carga y exploración de la base de datos proporcionada.

Identificación de las tablas y de las relaciones entre ellas.

Resolución de consultas SQL para extraer información específica.

Aplicación de funciones de agregación y agrupación para resumir datos.

Combinación de tablas mediante diferentes tipos de JOIN.

Utilización de subconsultas para resolver consultas de mayor complejidad.

Creación de vistas y tablas temporales.

Organización y documentación de las consultas en un archivo SQL.

4. Contenidos y conceptos trabajados

Los ejercicios abarcan los siguientes conceptos:

Consultas básicas con SELECT.

Filtrado de registros mediante WHERE, BETWEEN, IN y operadores lógicos.

Ordenación de resultados con ORDER BY y limitación de registros con LIMIT.

Funciones de agregación: COUNT, SUM, AVG, MIN, MAX, STDDEV y VARIANCE.

Agrupación de datos mediante GROUP BY y filtrado de grupos con HAVING.

Combinación de tablas mediante INNER JOIN, LEFT JOIN, RIGHT JOIN y CROSS JOIN.

Uso de subconsultas.

Creación de vistas mediante CREATE VIEW.

Creación y utilización de tablas temporales.

Buenas prácticas de organización, legibilidad y documentación del código SQL.

5. Estructura del repositorio

README.md: documentación del proyecto, metodología y conceptos trabajados.

consultas_proyecto.sql: archivo con las consultas correspondientes a los 64 ejercicios, identificadas mediante su número y enunciado.

BBDD_Proyecto_shakila_sinuser.sql: archivo original de la base de datos proporcionada, si se incluye en el repositorio.

6. Conclusiones

El desarrollo de este proyecto permite practicar SQL aplicado a una base de datos relacional y comprender cómo extraer, combinar y resumir información de distintas tablas.

Los ejercicios permiten trabajar desde consultas sencillas hasta operaciones que requieren relaciones entre tablas, subconsultas, vistas y estructuras temporales.

El proyecto constituye una práctica de los fundamentos de SQL y del uso de PostgreSQL y DBeaver para la exploración y consulta de datos
